# UNSEEN — The Mental Load

Detailed multi-page educational website prototype.

## Features
- Fixed left-side navigation
- Separate pages (not one scrolling page)
- Dark mode saved in localStorage
- Rotating quote and copy-quote feature
- Interactive reflection quiz
- Interactive scenarios
- Myth-or-reality activity
- Example CSS chart and data-literacy note
- Philippine context and selected official law-reference links
- Responsive mobile sidebar

## Run
Open `index.html` directly or use VS Code Live Server.

This is a frontend prototype. Verify all statistics, references, and legal information before formal publication.
